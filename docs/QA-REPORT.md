| TRV-022 jump + Wild consent | Declining the Wild prompt after confirming a jump keeps the singularity (both sources lose it); a two-phase confirmation must not commit state. Deliberate deviation in every ruleset. | accepted (M5) |
| NEWS-039 Palm arrival flags | The engine adds the Palm System Information news flags once per arrival; Palm re-adds them each time the screen opens, which can only push a later flag past the 4-flag cap. | accepted (M5) |
| NEWS-046 Palm page limit metrics | The engine applies Palm's `DisplayHeadline` rule with app-supplied `HeadlineMetrics`. The app (M9, `NewspaperText.palmMetrics`) measures the formatted headline with `PalmStdFont`, an approximate table of Palm OS `stdFont` advance widths (2–6 px per glyph) against the 148 px line; the exact ROM font metrics are not in the game source. A headline near the limit may therefore be kept or dropped differently than on a device; RNG output is independent of the page layout. | accepted (M5), app part M9 |
| NEWS-047 / UI-ENC-070 Palm Rsc texts | Checked on 2026-11-17 against the gitignored Palm source (`docs/reference/palm-src/Rsc/Resource.frk/Merchant.rsrc`): the 17 masthead lists (3 each) equal C# `NewsMastheads` once Palm's prefixes are read as C# placeholders (`* X` = "The ^1 X", `+ X` = "^1 X", as `SystemInfoEvent.c:441-460` prints them), and the 17 canned-story lists (4 each) equal C# `NewsHeadlines` byte for byte.
