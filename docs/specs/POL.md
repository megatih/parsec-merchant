# POL: Police, record, reputation and arrest

> Format (PRD §7): `- **ID** {Mn} [M][W][P] statement (source)`. `[M]` Modern, `[W]` Windows 2.01, `[P]` Palm 1.2.2.
> C# paths are relative to `/Users/megatih/Downloads/SpaceTraderSource201`. Palm paths are relative to `docs/reference/palm-src/`.
> **Modern = Windows 2.01 plus the closed MOD list (PRD §4.3).** A Windows quirk that no MOD entry fixes is tagged `[M][W]`.
> Every formula was re-read in the source on 2026-11-17. `[verify]` marks a statement that could not be confirmed fully. Quest-specific effects (Wild, reactor, sculpture, Princess, artifact, Jarek, antidote, Scarab) are `{M4}`.
> **Scope.** POL owns the police record and reputation scales, every record/reputation change, police inspections (submit, bribe, flee), the post-Marie customs yield, surrender (police, pirates, Mantis), arrest and jail, the escape pod and the arrival that follows them. Combat mechanics are CMB; encounter determination is ENC; littering is ECO-056/057; worth is BNK-004…006; insurance is BNK §8.
>
> **Notation.** `rec` = `commander.policeRecordScore`, `rep` = `commander.reputationScore`, `W` = commander worth per ruleset (BNK-004 [W], BNK-005 [P], BNK-006 [M] MOD-019). `D` = difficulty 0…4. `rand(n)` = one RNG draw (RNG-003/004). All divisions truncate toward zero unless a `double` is named. "Illegal goods" = Firearms and Narcotics.

## 1. Record and reputation scales

- **POL-001** {M3} [M][W][P] A new game starts with `rec = 0` (Clean) and `rep = 0` (Harmless). Both are unbounded signed integers; no rule clamps them except where a requirement below says so. (source: Commander.cs:35-44, :345-375; Palm: Src/Traveler.c:1639-1640)
- **POL-002** {M3} [M][W][P] Displayed police-record level by score, identical in all rulesets: Psychopath `rec < -70`, Villain `-70 ≤ rec < -30`, Criminal `-30 ≤ rec < -10`, Crook `-10 ≤ rec < -5`, Dubious `-5 ≤ rec < 0`, Clean `0 ≤ rec < 5`, Lawful `5 ≤ rec < 10`, Trusted `10 ≤ rec < 25`, Liked `25 ≤ rec < 75`, Hero `rec ≥ 75`. (source: Consts.cs:104-113, :159-171, PoliceRecord.cs:44-49; Palm: Src/Global.c:48-60, Src/CmdrStatusEvent.c:76-82)
- **POL-003** {M3} [M][W][P] The level lookup walks the table from Psychopath upward while `rec >= minScore` and returns the last level passed, or Psychopath if none (`max(0, i-1)`). Psychopath's own table minimum (−100) therefore never matters for display: −80 and −1000 are both Psychopath. The engine exposes `PoliceRecordType` (10 cases) and the app localizes the names (C# "Psychopath"/"Liked", Palm "Psycho"/"Liked"). (source: PoliceRecord.cs:44-49, Enums.cs:472-485; Palm: Src/CmdrStatusEvent.c:76-82)
- **POL-004** {M3} [M][W] C# `GetPoliceRecordFromScore(score)` ignores its argument and reads the commander's score; the engine function takes the score explicitly and every call site passes the commander's score, so results are identical. (source: PoliceRecord.cs:44-49)
- **POL-005** {M3} [M][W][P] Reputation levels by score, identical in all rulesets: Harmless < 10 (including negative), Mostly harmless 10, Poor 20, Average 40, Above average 80, Competent 150, Dangerous 300, Deadly 600, Elite ≥ 1500, looked up the same way as POL-003. (source: Consts.cs:115-123, :197-209, Reputation.cs:46-51; Palm: Src/spacetrader.h:378-386, Src/Global.c:63-74, Src/CmdrStatusEvent.c:84-90)
- **POL-006** {M3} [M][W] Rule constants used *in code* (not for display): psychopath −100, villain −70, criminal −30, crook −10, dubious −5, clean 0, lawful 5, trusted 10, liked 25, hero 75. (source: Consts.cs:104-113)
- **POL-007** {M5} [P] Palm's code constants are one level lower for the three criminal names: `PSYCHOPATHSCORE −70`, `VILLAINSCORE −30`, `CRIMINALSCORE −10` (dubious −5, clean 0, lawful 5, trusted 10, helper 25, hero 75 unchanged). Every Palm rule written with these names (POL-031, POL-034, POL-038, POL-075, RUL-074/075/089/144) triggers at the Palm value. Flag `policeConstantFamily` (RUL-130). (source: Palm: Src/spacetrader.h:365-373)
- **POL-008** {M3} [M][W][P] Record score deltas: attack police −3, attack trader −2, attack pirate 0, caught with Wild −4, flee inspection −2, kill police −6, kill trader −4, kill pirate +1, plunder trader −2, plunder pirate −1, trafficking −1; kill captain is a **reputation** bonus of +100. Palm defines the same values (`TAKEMARIENARCOTICS −4` exists but is never used). C#'s `BountyModifier`, `CloakBonus` and `ReactionIllegal` are unused. (source: Consts.cs:51, :67, :125-136; Palm: Src/spacetrader.h:350-362)
- **POL-009** {M3} [M][W][P] "Criminal" in price and loan rules means `rec < -5` (ECO criminal sell factor) or `rec < 0` (BNK-011 max loan); POL does not redefine them. (source: Game.cs, Form_ViewBank.cs:62-65; Palm: Src/Skill.c, Src/Bank.c:40-44)

## 2. Record drift over time

- **POL-010** {M3} [W] Inside `IncDays(n)` (every day advance: warp, jail term, escape-pod days): if `rec > 0` then `rec = max(0, rec - n/3)`; else if `rec < -5` then `rec = min(-5, rec + n/(D <= Normal ? 1 : D))`. With `n = 1` a positive record never decays and on Hard/Impossible a criminal record never improves (research 01 §13 #3). (source: Game.cs:2590-2596, RUL-103)
- **POL-011** {M5} [M][P] MOD-003: once per warp, **including** singularity jumps and never inside `IncDays`, after the day advance of a normal warp: `if days % 3 == 0 && rec > 0 { rec -= 1 }`, then `if rec < -5 { if D <= Normal || days % D == 0 { rec += 1 } }`. Jail and pod days cause no drift. (source: Palm: Src/Traveler.c:560-589, PRD §4.3 MOD-003, RUL-103)
- **POL-012** {M3} [M][W][P] Examples: [W] `rec = 30`: a 1-day warp leaves 30 (`1/3 = 0`), the pod's `IncDays(3)` gives 29; `rec = -20` on Hard: a 1-day warp adds `1/3 = 0`, a 30-day `IncDays` adds 10. [M][P] `rec = 30`: a warp landing on day 9 gives 29, jail and pod days give nothing; `rec = -20` on Hard improves by 1 on warps landing on a day divisible by 3. (source: Game.cs:2590-2596; Palm: Src/Traveler.c:580-589)

- **POL-032** {M3} [M][W][P] Attacking a trader in `traderIgnore`, `traderBuy` or `traderSell`: if `rec < 0` then `rec -= 2` (no confirmation); else the command needs `WarningID.attackTrader` and then sets `rec = -5`. - **POL-033** {M3} [M][W] Attacking Ahab, Conrad or Huie always needs `WarningID.attackCaptain`; then `rec = min(rec, -70) - 2`, the news event "Captain X attacked" is added and the type becomes `famousCaptainAttack`. Attacking an already-attacking captain changes nothing. (source: Game.cs:1669-1697)
- **POL-034** {M5} [P] Palm captains: the confirmation is asked only while the type is not yet `famousCaptainAttack`, but `rec = min(rec, -30) - 2` is applied on **every** attack round (manual or automatic); the news event is added only on the first. (source: Palm: Src/Encounter.c:1551-1568)
- **POL-035** {M3} [M][W] Fleeing an inspection: if nothing illegal is detectable (POL-051) the command first needs `WarningID.fleeInspection`; then the type becomes `policeAttack` and `rec = min(rec - 2, -5 - (D >= Normal ? 1 : 0))`. (source: Game.cs:1762-1787)
- **POL-036** {M3} [M][W] Fleeing post-Marie customs needs `WarningID.fleeMariePolice`; then the type becomes `policeAttack` and `rec = min(rec - 3, -30)`. (source: Game.cs:1771-1787)
- **POL-037** {M5} [P] Palm fleeing an inspection: the nothing-illegal confirmation (`WarningID.fleeInspection`) is asked when the player carries no Firearms, no Narcotics, no Wild and no reactor; then `rec = rec > -5 ? -5 - (D >= Normal ? 1 : 0) : rec - 2` and the type becomes `policeAttack`. - **POL-038** {M5} [P] Palm fleeing customs (confirmation `fleeMariePolice`): `rec = rec >= -10 ? -10 : rec - 3`, type `policeAttack`. (source: Palm: Src/Encounter.c:1601-1615, RUL-135)
- **POL-039** {M3} [M][W][P] Attacking pirates, the Space Monster, the Dragonfly, the Scarab or the Scorpion, and fleeing from any attacking ship (police included), changes no record (`ScoreAttackPirate = 0`). (source: Game.cs:1607-1615, :1762-1789; Palm: Src/Encounter.c:1509-1550)

## 4. Police inspection

- **POL-050** {M3} [M][W][P] In `policeInspect` the player may attack (POL-030/031), flee (POL-035/037), submit (§4) or bribe (§5). Ignore is not offered. (source: Form_Encounter.cs:1136-1141; Palm: Src/Encounter.c:127-138)
- **POL-051** {M3} [M][W] `detectableIllegalCargo = (cargo[Firearms] + cargo[Narcotics]) - hiddenCargoBays > 0`; `illegalSpecialCargo = Wild aboard || reactor aboard || sculpture aboard`; `detectableIllegalCargoOrPassengers` = either. (source: Ship.cs:882-902, :1131-1137)
- **POL-052** {M5} [P] Palm has no hidden bays and no sculpture: illegal goods are `cargo[Firearms] > 0 || cargo[Narcotics] > 0`; Wild means `WildStatus == 1`; the reactor means `0 < ReactorStatus < 21`. (source: Palm: Src/Encounter.c:1488-1490, :1588-1590, :2041-2044)
- **POL-053** {M3} [M][W] When `!detectableIllegalCargoOrPassengers`, attack and bribe in `policeInspect` first need `WarningID.submitWithNothingIllegal` (flee needs `.fleeInspection`, POL-035); the bribe confirmation of POL-066 follows as a second acknowledgement. (source: Game.cs:1617-1623, :1736-1737, :1766-1767)
- **POL-054** {M5} [P] Palm nothing-illegal conditions differ per action: attack asks when no Firearms and no Narcotics (Wild and the reactor are ignored); flee asks when no Firearms, Narcotics, Wild or reactor; bribe asks when no Firearms, Narcotics or Wild (the reactor is ignored). (source: Palm: Src/Encounter.c:1487-1492, :1588-1593, :1986-1991)
- **POL-055** {M3} [M][W] Submit when `detectableIllegalCargoOrPassengers`: the command needs `WarningID.submitWithIllegalGoods` (the confirmation lists Wild, reactor, sculpture and detectable goods and states that arrest follows when special cargo is aboard); declining changes nothing. Without anything detectable, submit needs no confirmation. (source: Game.cs:1791-1803, Ship.cs:640-662)
- **POL-056** {M3} [M][W] Submitting with `detectableIllegalCargo`: all Firearms and Narcotics are removed **including units in hidden bays**, and their `priceCargo` is set to 0; `fine = (int)max(100, min(10000, ceil((double)W / ((4 - D + 2) * 10) / 50) * 50))`; `cashPayment = min(cash, fine)`; `debt += fine - cashPayment`; `cash -= cashPayment`; `rec -= 1`; event `policeFine(amount: fine)`. (source: Game.cs:1805-1818, Ship.cs:721-731, RUL-138)
- **POL-057** {M3} [M][W] Fine examples (Normal, divisor 40): W = 11000 → 275/50 = 5.5 → 6 → 300; W = 10001 → 5.0005 → 6 → 300; W = 3000 → 100 (floor); W = 1,000,000 → 10000 (cap); W ≤ 0 → 100. Beginner divides by 60, Impossible by 20. (source: Game.cs:1809-1810)
- **POL-058** {M3} [M][W] Submitting with nothing detectable and no special cargo: `rec += 1`, event `inspectionClean`; illegal goods hidden in hidden bays stay aboard with their cost basis. (source: Game.cs:1820-1828)
- **POL-059** {M3} [M][W] After a submit that included `illegalSpecialCargo`, the encounter ends in arrest (§8), after the fine and −1 of POL-056 (if goods were detectable). Without special cargo the encounter ends normally. (source: Form_Encounter.cs:1279-1283)
- **POL-060** {M5} [P] Palm submit asks `submitWithIllegalGoods` when Firearms, Narcotics or Wild are aboard or `1 < ReactorStatus < 21` (status 1 skips the warning, RUL-139). (source: Palm: Src/Encounter.c:2041-2077)
- **POL-061** {M5} [P] Palm submitting with illegal goods: Firearms and Narcotics and their `BuyingPrice` are cleared; `fine = W / ((4 + 2 - D) * 10)` (integer), rounded **up** to a multiple of 50 (`fine % 50 != 0 → fine += 50 - fine % 50`), clamped to 100…10000; paid from cash, the shortfall to debt; `rec -= 1`. Example: W = 10001 on Normal → 250 (C# 300). (source: Palm: Src/Encounter.c:2079-2110)
- **POL-062** {M5} [P] Palm: with no illegal goods, `rec += 1` only if Wild is not aboard. Then if Wild is aboard the player is arrested (§8). Otherwise, if the reactor is aboard it is confiscated (`ReactorStatus = 0`, event `reactorConfiscated`) **without arrest** and the trip continues. (source: Palm: Src/Encounter.c:2111-2131, RUL-139)
- **POL-063** {M3} [M][W][P] A completed submit without arrest ends the encounter and transit resumes; the trip's `inspected` flag set when the inspection was generated keeps further inspections away this trip (ENC). (source: Form_Encounter.cs:1281-1282, Game.cs:903; Palm: Src/Encounter.c:2302-2306)

## 5. Bribe

- **POL-065** {M3} [M][W] Bribe checks in order: `marieCelestePolice` → `CommandError.bribeRefusedCustoms`; destination government `bribeLevel <= 0` → `CommandError.bribeNotPossible`; nothing illegal detectable → `WarningID.submitWithNothingIllegal`. Bribe levels: Anarchy 7, Capitalist 1, Communist 5, Confederacy 3, Corporate 2, Cybernetic 0, Democracy 2, Dictatorship 2, Fascist 0, Feudal 6, Military 0, Monarchy 4, Pacifist 1, Socialist 6, Satori 0, Technocracy 2, Theocracy 0 (same in Palm). (source: Game.cs:1728-1738, Consts.cs:177-193; Palm: Src/Global.c:335-354)
- **POL-066** {M3} [M][W] `diffMod = 10 + 5*(4 - D)`; `passMod = illegalSpecialCargo ? (D <= Normal ? 2 : 3) : 1` (Wild, reactor **or sculpture**); `bribe = max(100, min(10000, (int)ceil((double)W / bribeLevel / diffMod / 100) * 100 * passMod))`. The command then needs `WarningID.bribe` with `amounts: [bribe]`. (source: Game.cs:1739-1746, RUL-140)
- **POL-067** {M5} [P] Palm bribe checks: `bribeLevel <= 0` → `bribeNotPossible` **before** the customs check (`bribeRefusedCustoms`); then the Palm nothing-illegal confirmation (POL-054). `bribe = W / ((10 + 5*(4 - D)) * bribeLevel)` (integer), rounded up to a multiple of 100 by `%` (a negative quotient rounds toward zero), ×2 (D ≤ Normal) or ×3 only when Wild or the reactor is aboard, clamped to 100…10000. (source: Palm: Src/Encounter.c:1975-2006, research 04 errata #5)
- **POL-068** {M3} [M][W][P] Bribe examples (Normal, diffMod 20, bribe level 1): W = 11000 → C# `ceil(5.5) = 6` → 600; Palm `550` → 600. W = 10001 → C# 600, Palm 500. With the reactor aboard on Hard (diffMod 15): W = 30000 → C# `ceil(20) * 100 * 3 = 6000`, Palm `2000 * 3 = 6000`. With only the sculpture aboard C# multiplies, Palm has no sculpture. (source: Game.cs:1741-1744; Palm: Src/Encounter.c:1995-2006)
- **POL-069** {M3} [M][W][P] An acknowledged bribe with `cash < bribe` (cash, not cash-to-spend) is rejected with `CommandError.bribeInsufficientCash` and the encounter stays. Otherwise `cash -= bribe`, event `bribePaid(amount:)`, the encounter ends and transit resumes. A bribe never changes the record. (source: Game.cs:1748-1757, Form_Encounter.cs:1230-1234; Palm: Src/Encounter.c:2018-2031)

## 7. Surrender

- **POL-075** {M3} [M][W][P] Surrender to police (C# `policeAttack`/`policeSurrender`; Palm `policeAttack`): rejected with `CommandError.surrenderRefused` if `rec <= psychopath` (−100 [M][W], −70 [P], RUL-133); otherwise it needs `WarningID.surrenderToPolice` (amounts empty; the preview lists Wild, reactor and sculpture consequences) and then the player is arrested (§8). (source: Game.cs:1852-1859; Palm: Src/Encounter.c:1864-1897)
- **POL-076** {M4} [M][W][P] Surrender to the Mantis: without the artifact aboard it is rejected with `surrenderRefused`; with it, it needs `WarningID.surrenderArtifact`, then the artifact status becomes 0 (C# `StatusArtifactNotStarted`; Palm `ArtifactOnBoard = false`), event `artifactSurrendered`, and the encounter ends. (source: Game.cs:1837-1851; Palm: Src/Encounter.c:1846-1862)
- **POL-077** {M4} [M][W] Surrender to pirates with the Princess aboard and no hidden cargo bays is rejected with `CommandError.surrenderRefusedPrincessAboard`. (source: Game.cs:1860-1863)
- **POL-078** {M3} [M][W] Otherwise surrendering to pirates (or to the Scarab, which takes the same branch) needs no confirmation and sets the trip's `raided = true` (ENC), then in order: (1) with hidden bays fitted: event `preciousCargoHidden(items:)` listing the Princess and/or sculpture if aboard; (2) else with the sculpture aboard: sculpture status 0, event `piratesTookSculpture` {M4}; (3) loot or blackmail (POL-079…POL-082); (4) Wild (POL-084); (5) reactor aboard: event `piratesIgnoredReactor` {M4}; then the encounter ends. (source: Game.cs:1864-1934)
- **POL-079** {M3} [M][W] Stealable list: every unit of normal cargo, sorted by **trade-item index descending** (Robots, Narcotics, Machines, … Water; the source comment says "most expensive" but sorts by index); then `protected = hiddenCargoBays - (Princess aboard ? 1 : 0) - (sculpture aboard ? 1 : 0)`; if `protected > 0` the first `protected` units are removed from the list (they stay aboard). (source: Ship.cs:1280-1306)
- **POL-080** {M3} [W] When `protected` exceeds the number of cargo units (including an empty hold), C# `RemoveRange` throws and the surrender aborts after step (1) of POL-078: the engine keeps `raided = true` and the `preciousCargoHidden` event, steals nothing, charges no blackmail, skips steps (4)-(5) and leaves the encounter open in its current type (the WinForms "Continue" outcome). [verify: modelled abort of an unhandled exception] (source: Ship.cs:1300-1301, RUL-112)
- **POL-081** {M5} [M] MOD-012: `protected = min(max(0, protected), units)`; if every unit is protected the list is empty and POL-082's blackmail applies. (source: PRD §4.3 MOD-012, RUL-112)

## 8. Arrest

- **POL-088** {M3} [M][W][P] Arrest happens after: surrender to police (POL-075), yield with special cargo (POL-071/073), submit with special cargo ([M][W] POL-059) or with Wild ([P] POL-062). It ends the encounter and the transit (no further clicks, C# `Clicks = 0`). (source: Game.cs:3130-3134, Form_Encounter.cs:1282; Palm: Src/Encounter.c:1896, :2120)
- **POL-089** {M3} [M][W] At the start of the arrest, from the current values: `term = max(30, -rec)` days; `fine = (1 + W * min(80, -rec) / 50000) * 500`; with Wild aboard `fine = (int)(fine * 1.05)`. The products use Int32 wrapping arithmetic (`&*`) as the source does. (source: Game.cs:202-207)
- **POL-090** {M5} [M] MOD-002: `fine = (1 + W * min(80, max(0, -rec)) / 50000) * 500`, so the fine is ≥ 500 (≥ 525 with Wild). (source: PRD §4.3 MOD-002, RUL-102)
- **POL-091** {M5} [P] Palm: `fine = (1 + ((W * min(80, -rec)) / 100) / 500) * 500`, ×1.05 truncated with Wild (`WildStatus == 1`); `term = max(30, -rec)`. Palm keeps the negative-fine bug. (source: Palm: Src/Encounter.c:666-671, RUL-136)
- **POL-092** {M3} [M][W][P] Fine examples: [W] W = 11000, rec −10 → `1 + 110000/50000 = 3` → 1500, term 30; with Wild 1575. [W] rec +5 → `-55000/50000 = -1` → 0; rec +10 → −500 (cash **increases** by 500, research 01 §13 #2); [M] both → 500. [P] W = 10000, rec −10 → 1500; rec +10 → `(1 + (-1000/500)) * 500 = -500`. rec −200 → term 200, multiplier 80. (source: Game.cs:205; Palm: Src/Encounter.c:666)
- **POL-093** {M3} [M][W] Arrest sequence, in this order: events `arrested` and `convicted(days: term, fine: fine)`; (1) every hidden-cargo-bays gadget removed (`hiddenCompartmentsRemoved`); (2) reactor aboard → reactor status 0 (`reactorConfiscated`) {M4}; (3) sculpture aboard → status 0 (`sculptureConfiscated`) {M4}; (4) Wild aboard → status 0, news `wildArrested`, event `wildArrested` {M4}; (5) any illegal goods → removed with cost basis cleared (`illegalGoodsImpounded`); (6) insured → `insured = false`, `noClaim = 0` (`insuranceLost`, BNK-046); (7) mercenaries (POL-094); (8) Jarek aboard → status 0 (`jarekTakenHome`) {M4}; (9) Princess aboard → status 0 (`princessTakenHome`) {M4}; (10) antidote in transit → Japori status 2 (done; `antidoteTakenOnArrest`) {M4}; (11) fine (POL-095); (12) debt and interest (BNK-025); (13) `rec = -5`; (14) `IncDays(term)` (POL-097). (source: Game.cs:202-307)
- **POL-094** {M3} [M][W] Mercenaries: only when `crewCount - specialCrewCount > 1` (two or more non-special crew, CRW-047) every crew slot from 1 up is cleared — **including** Wild, Jarek and the Princess — with event `mercenariesLeft`. Otherwise nobody leaves. (source: Game.cs:254-259, Ship.cs:1260-1278, Consts.cs:282-295)
- **POL-095** {M4} [M][W] Port quirk derived from POL-093 order (RUL audit row needed): steps (8)-(9) test "aboard" **after** step (7). With ≥ 2 mercenaries, Jarek and the Princess leave the ship in step (7) but keep their quest status (the quest is stuck); with fewer, all special passengers stay aboard with status 0 and the `IncDays(term)` of step (14) then advances each status by one (to 1) while they remain aboard, unless the ship was sold (step 11). [verify: derived from statement order; no source comment] (source: Game.cs:236-273, :2632-2680)
- **POL-096** {M3} [M][W] Fine: if `cash >= fine` then `cash -= fine` (a negative fine adds cash); otherwise `cash = max(0, cash + shipWorth(forInsurance: true) - fine)` (base worth after the hidden bays were removed, plus `Σ priceCargo` with the illegal entries already 0), events `shipSoldToPayFine`, `tribblesSoldWithShip` if tribbles were aboard, `fleaProvided(cost: 0)`, and the ship becomes a new Flea (`CreateFlea`: Flea spec, full hull and fuel, commander only, no pod, `insured = false`, `noClaim = 0`). - **POL-097** {M3} [M][W] `IncDays(term)` after `rec = -5` (so POL-010 drift does nothing: −5 is not below −5); quest timers advance by `term` (reactor already 0, Gemulon, experiment, fabric rip), the Space Monster regrows, and `noClaim` does not grow (insurance was cancelled). (source: Game.cs:305-306, :2584-2622)
- **POL-098** {M5} [P] Palm arrest sequence: events `arrested`, `convicted`; (1) Firearms and Narcotics removed, `BuyingPrice` **kept** (RUL-138); (2) insurance lost; (3) if crew slot 1 is filled, slots 1…2 cleared (`mercenariesLeft`, CRW-048); (4) antidote → Japori status 2; (5) Jarek status 1 → 0; (6) Wild status 1 → 0, news; (7) reactor (0 < status < 21) → 0; (8) `Arrival()` (current system = destination, status shuffle, quantities, prices); (9) `IncDays(term)` (no record drift, no no-claim); (10) fine: `cash >= fine ? cash -= fine : { cash += CurrentShipPrice(true); cash = cash >= fine ? cash - fine : 0; tribbles = 0; CreateFlea() }`; (11) `rec = -5`; (12) debt paydown `min(cash, debt)`; (13) `PayInterest()` `term` times (BNK-026).
