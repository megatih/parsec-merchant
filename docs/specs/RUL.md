# RUL: Ruleset diff matrix

> Format (PRD §7): `- **ID** {Mn} [M][W][P] statement (source)`. Tags: `[UI]` = covered by app or UI tests; `[manual]` = covered by a QA-REPORT row.
>
> **Rulesets.** **Modern** (default; Windows 2.01 with the closed MOD list of PRD §4.3 applied), **Windows 2.01** (faithful C# port, quirks included), **Palm 1.2.2** (faithful Palm rules and content, quirks included). The ruleset is chosen at New Game and stored immutably in the save.
>
> **Engine rule (hard).** Every row below is exposed as data on `Ruleset` (`tables`, `flags: RuleFlags`, `content: ContentPacks`, `rngKind`). Engine systems read the flag or content value; they **never** branch on `ruleset.id`.
>
> **Reading the tables.** Each value column names the behaviour that ruleset uses. Unless a row cites a MOD or the PRD "kept as designed" list, **Modern equals Windows 2.01** (PRD §4.3). Sources: C# lines are in `/Users/megatih/Downloads/SpaceTraderSource201` (`File.cs:line`); Palm citations are `Src/File.c:Function` (or `Src/spacetrader.h:MACRO`) in the local Palm 1.2.2 copy. Every value was re-read in the source on 2026-11-16; anything that could not be confirmed is marked **[verify]**. Research docs 01/04 and their QA ERRATA were the starting checklist; discrepancies found while verifying are listed at the end.
>
> **Notation.** `D` = difficulty (Beginner 0 … Impossible 4); `rec` = police record score; `rand(n)` = uniform integer in `[0, n)`; `floor`/`trunc` = integer truncation as in the source. Requirement IDs in tables are plain text; the bold IDs live in the Requirements section.

## 6. Open points and discrepancies

- **[verify] MOD-017 and the ship designer.** C# custom ships take fuel cost `COST_FUEL[size]` (1,1,1,3,5,10) and repair cost `COST_HULL[size]` (1,5,10,15,20,40) (`Shipyard.cs:38`, `Shipyard.cs:120`). Palm has no designer, so whether these columns are also swapped cannot be checked; Modern keeps them as in C# until the owner decides.
- **Palm game RNG stand-in (accepted assumption, docs/QA-REPORT.md).** The ROM `SysRandom` algorithm is not in the game source; the Palm ruleset's LCG parameters are a documented stand-in (PRD §4.2, RNG-026).
- **Audit candidate (not a MOD).** In Windows 2.01 the escape pod keeps Scarab status 3, so the hull-halving rule still applies to the new Flea (`Game.cs:2031`, `Game.cs:1367`). Modern keeps this per RUL-003 (RUL-099); changing it needs a RUL audit row.
- **Palm also has the negative-fine bug** (`Src/Encounter.c:Arrested` uses `min(80, −PoliceRecordScore)`), so RUL-102 keeps it in Palm.
- **Transit length.** Both ports perform 20 encounter checks; Palm's `Clicks = 21` is a sentinel (RUL-069), not an extra click.
- **Not differences** (research listed them as candidates): extra bays counted in opponent cargo (both), equipment purchase while in debt (blocked in both), high-score tie-break (both prefer more days), Wild-at-Kravat police odds (both 25/33/50%), random events on Acamar (impossible in both).
