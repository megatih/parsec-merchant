# NEWS: Newspaper

> Format (PRD §7): `- **ID** {Mn} [M][W][P] statement (source)`. `[M]` Modern, `[W]` Windows 2.01, `[P]` Palm 1.2.2. A bullet carries only the tags of the rulesets for which it holds; differing values get separate bullets.
> Milestones: Windows 2.01 baseline and shared behaviour {M3}; Palm-only variants {M5}; quest-dependent headlines are exercised by QST scenarios in {M4} but their composition rules are specified here.
> C# sources are relative to `/Users/megatih/Downloads/SpaceTraderSource201`; Palm sources are `docs/reference/palm-src/Src/…`. Every value was re-read from source on 2026-11-16; `[verify]` marks what could not be confirmed from source alone.
> **Modern = Windows 2.01** for the newspaper (no MOD entry touches it). Flag names come from RUL.md (`newsVillainThreshold`, `newsHeroRule`, `newsDistantRange`, `newsCannedBound`, `newsPageLimit`); flags not yet in RUL.md are listed in §6.
> Notation: `D` = difficulty 0…4; `cur` = current system; `GetRandom2(n)` = `PieterRand.rand() % n` (RNG.md §5), never the game RNG; `TL` = tech level 0…7; `N` = number of systems.
> **The engine emits no strings.** It produces typed headline records; the app formats them from the string tables cited below (C# `Strings.cs`; Palm reuses the C# texts per PRD §4.4 and RUL-018).

## 1. Cost, purchase and options

- **NEWS-001** {M3} [M][W][P] A newspaper costs `D + 1` credits (1 on Beginner … 5 on Impossible). (source: Game.cs:3029; Palm: Src/SystemInfoEvent.c:397-411)
- **NEWS-002** {M3} [M][W][P] `paidForNewspaper` is set to false by every arrival (including the arrival after an arrest or escape pod) and to true by a purchase, so the paper is paid at most once per system visit and can be re-read for free until the next arrival. It is part of `GameState` and saved. (source: Game.cs:313, :3036-3037, :3066; Palm: Src/Traveler.c:2440, Src/SystemInfoEvent.c:406-410)
- **NEWS-003** {M3} [M][W][P] `perform(.readNewspaper)` is accepted only in `.docked` with no pending decision (else `notAllowedInPhase` / `pendingDecisionFirst`). (source: Form_SpaceTrader.cs:3576-3579; Palm: Src/SystemInfoEvent.c:395)
- **NEWS-004** {M3} [M][W] When unpaid and `cash < cost`, `.readNewspaper` is rejected with `CommandError.newspaperUnaffordable` (ALR-009). The test uses cash, not cash-to-spend. (source: Game.cs:3031-3032)
- **NEWS-005** {M5} [P] When unpaid and `ToSpend() < cost` (BNK-055, so `ReserveMoney` can block it), `.readNewspaper` is rejected with `newspaperUnaffordable`. Flag `newspaperUsesCashToSpend` (§6). (source: Palm: Src/SystemInfoEvent.c:399-403)
- **NEWS-006** {M3} [M][W][P] When unpaid, affordable and `options.newsAutoPay` is on, the step deducts the cost, sets `paidForNewspaper = true`, emits `.boughtNewspaper(cost:)` and returns the paper. (source: Game.cs:3033-3038; Palm: Src/SystemInfoEvent.c:405-410)
- **NEWS-007** {M3} [M][W][P] When unpaid, affordable and auto-pay is off, `.readNewspaper` without `acknowledging: [.buyNewspaper]` returns `needsConfirmation(Confirmation(.buyNewspaper, amounts: [cost]))` and changes nothing (ALR-006); with the acknowledgement it pays as in NEWS-006. (source: Game.cs:3033-3034; Palm: Src/SystemInfoEvent.c:405-407)
- **NEWS-008** {M3} [M][W][P] When already paid, `.readNewspaper` charges nothing, emits no event and returns the paper. (source: Game.cs:3027, :3042-3043; Palm: Src/SystemInfoEvent.c:399, :408)
- **NEWS-009** {M3} [M][W][P] The paper is returned as `decision: .newspaper(Newspaper)`. This decision is informational: it is not stored in `GameState` and blocks no command. `preview(.newspaper)` returns the same `Newspaper` when `paidForNewspaper` is true and `nil` otherwise. (source: Game.cs:3042-3043; PRD §6.2)
- **NEWS-010** {M3} [M][W][P] Composition is a pure function of the state: it reseeds `PieterRand` (RNG-025) every time and never draws from the game RNG, so reading the paper twice in one visit yields identical headlines and leaves the canonical state hash unchanged. (source: Game.cs:3919-3921; Palm: Src/SystemInfoEvent.c:465)
- **NEWS-011** {M3} [M][W] Options `newsAutoPay` and `newsAutoShow` both default to false. (source: GameOptions.cs:42-43)
- **NEWS-012** {M3} [M][W] When `options.newsAutoShow` is on, the end of the arrival pipeline (TRV-050 step 10) applies the purchase rules without a separate command: unaffordable → the arrival events include `.newspaperUnaffordable(cost:)`; auto-pay on → the paper is bought (`.boughtNewspaper(cost:)`) and `ArrivalReport.newspaper` holds it; otherwise `ArrivalReport.newspaperOffer = cost`, and the player accepts by sending `.readNewspaper` acknowledging `.buyNewspaper` (declining needs no command). The same applies when a new game starts with auto-show on. (source: Game.cs:328-329, :3025-3044, Form_SpaceTrader.cs:3702-3703)
- **NEWS-013** {M5} [P] Palm has `NewsAutoPay` (default false) but no auto-show option: the paper is shown only on request. Flag `newsAutoShowAvailable` (§6). (source: Palm: Src/Global.c:666, Src/AppHandleEvent.c:267-278)

(source: Game.cs:3908, :3924, :3933, :3939)

## 3. Windows composition (C# `NewspaperText`)

- **NEWS-017** {M3} [M][W] Masthead: `government = cur.politics`, `index = cur.id % 3`. (source: Game.cs:3905-3906)
- **NEWS-018** {M3} [M][W] Composition starts with `RandSeed(cur.id, days)`; a system id 0 (Acamar) or day 0 selects the default seed for that half (RNG-025). (source: Game.cs:3921, Functions.cs:268-277)
- **NEWS-019** {M3} [M][W] Step 1: one `.event(e)` per element of `newsEvents`, in list order (insertion order after replacements, §4). (source: Game.cs:3923-3925)
- **NEWS-020** {M3} [M][W][P] Step 2: if the current system has a pressure (Palm status > 0), `.localPressure(pressure)`; no draw. (source: Game.cs:3927-3928; Palm: Src/SystemInfoEvent.c:591-617)
- **NEWS-021** {M3} [M][W] Step 3 (`newsVillainThreshold`, `newsHeroRule`): if `record <= −70`, `.villain(variant: GetRandom2(4))`; **else** if `record >= 75`, `.hero(variant: GetRandom2(3))`; otherwise no draw. (source: Game.cs:3930-3940, Consts.cs:105, :113)
- **NEWS-022** {M3} [M][W] Step 4 (`newsDistantRange`): for `i = 0…N−1` in index order, for each system with `destOk(i)` (TRV-001, using current fuel or a wormhole from `cur`): (a) if its special event is `Moon`, `.moonForSale(i)`, else if it is `TribbleBuyer`, `.tribbleBuyer(i)`; (b) if it has a shipyard, `.shipyard(i)`; (c) if it has a pressure, draw `GetRandom2(100)`, and if the draw `<= 6 × cur.TL + 10 × (5 − D)` draw `prefix = GetRandom2(6)`, append `.distantPressure(prefix, pressure, i)` and set `realNews = true`. (source: Game.cs:3945-3973, Consts.cs:92)
- **NEWS-023** {M3} [M][W] In step 4 the `GetRandom2(100)` draw happens only for systems with a pressure (short-circuit `&&`), and the prefix draw only when the story passes; moon, tribble-buyer and shipyard stories draw nothing and do not set `realNews`. (source: Game.cs:3963-3970)
- **NEWS-024** {M3} [M][W][P] The story threshold uses `StoryProbability = 50/8 = 6` (integer): Hi-Tech (7) on Normal gives `42 + 30 = 72`, so a draw of 0…72 passes (73%); Pre-Agricultural on Impossible gives `0 + 10 = 10` (11%); Hi-Tech on Beginner gives `42 + 50 = 92` (93%). (source: Consts.cs:92, Game.cs:3964; Palm: Src/spacetrader.h:310, :333, Src/SystemInfoEvent.c:705)
- **NEWS-025** {M3} [M][W] Step 5 (`newsCannedBound`): if `realNews` is false, `toShow = GetRandom2(4)` is drawn **once**; then for `k = 0…toShow`, `idx = GetRandom2(4)` and `.canned(cur.politics, idx)` is appended unless `idx` was already shown. So at least one and at most four canned headlines appear, using `toShow + 2` draws in total. (source: Game.cs:3977-3991)
- **NEWS-026** {M3} [M][W] Example: `toShow = 2` and index draws 3, 3, 0 give `[.canned(g, 3), .canned(g, 0)]`. (source: Game.cs:3982-3990)
- **NEWS-027** {M3} [M][W] Modern and Windows print every headline: there is no page-length limit (`newsPageLimit` off). (source: Game.cs:3994)
- **NEWS-028** {M3} [W] Golden tests compose the newspaper for harness fixture states (seed, day, system, record, fuel, pressures) and match the C# harness output headline for headline. (source: PRD §8.4; Game.cs:3912-3995)

- **NEWS-029** {M3} [M][W] `newsEvents` is an ordered, unbounded list of `NewsEvent` that allows duplicates and is saved with the game. (source: Game.cs:57, :168, :3068, :2714-2717)

## 6. Open points and discrepancies

- **Flags this spec needs that RUL.md does not list yet** (each defaults to the Windows behaviour): `newspaperUsesCashToSpend` (NEWS-005), `newsAutoShowAvailable` (NEWS-013), `newsEventCapacity` and its membership-only semantics (NEWS-035), `newsSeedSystem` (current system vs warp target, NEWS-040), `newsEventOrdering` (insertion order vs Palm fixed order, NEWS-041).
- **C# quirks kept in Modern (no MOD entry):** the singularity `experimentArrival` headline never appears and the departure's own `experimentPerformed` headline is cleared (TRV-023, TRV-029). Palm shows both. Audit candidates.
- **Palm quirk:** at Gemulon before the invasion quest starts (special `GEMULONRESCUED`, no rescued flag) Palm prints "Alien Invasion Devastates Planet!"; after a real invasion the special becomes `GEMULONINVADED` and that headline no longer appears (NEWS-041). Reproduced as written.
- **Research 01 §6 says "A pressure story appears if `GetRandom2(100) <= 6*tech + 10*(5-diff)`"** but omits that the draw happens only for systems with a pressure and that moon, tribble and shipyard stories do not count as real news (NEWS-023). Research 04 §3 lists "Sources say" without noting it differs from C#.
- **Research 04 §3 says the Palm masthead uses `WarpSystem % 3` but does not note** that `WarpSystem` follows the player's later target selection (NEWS-040), nor the 4-flag cap and fixed headline order (NEWS-035, NEWS-041).
- **ALR naming:** this spec uses `CommandError.newspaperUnaffordable` and `WarningID.buyNewspaper` with the cost in `Confirmation.amounts` (the code's `WarningID` has no payloads); ALR-006/009 write them with `(cost:)` payloads.
