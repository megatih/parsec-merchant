# OPT: Game options

> Format (PRD §7): `- **ID** {Mn} [M][W][P] statement (source)`. `[M]` Modern, `[W]` Windows 2.01, `[P]` Palm 1.2.2. `[UI]` marks requirements covered by app or UI tests.
> Milestones: the options model, defaults, `Command.setOptions` and its normalization, and the behaviour map are {M6} (traced now, although the skeleton planned M2: each option's *effect* was already specified and tested in its owning spec at M2–M5, and this spec ties them together); the Options sheet, the defaults template and Settings are {M7} [UI]; the tracked-range display is {M8} [UI].
> C# sources are relative to `/Users/megatih/Downloads/SpaceTraderSource201` (read with `iconv -f cp1252 -t utf-8`); Palm sources are `docs/reference/palm-src/Src/…`. Every citation was re-read on 2026-11-17.
> **Two kinds of settings (UX-VISION §2).** *Per-save game options* are the classic `GameOptions`. They live in `GameState.options`, are saved with the game, change only through `Command.setOptions`, and are edited in **Game › Options…** (⌥⌘O). *App-wide settings* (Text Size, fast travel, sound, flavor…) live in `UserDefaults`, are edited in **Settings** (⌘,), and never reach the engine.
> Field names are those of `GameOptions` in `Packages/ParsecKit/Sources/ParsecEngine/Model/GameState.swift`; C# property names in parentheses, Palm globals in brackets.

## 1. Model and defaults

- **OPT-001** {M6} [M][W][P] `GameOptions` (Codable, Sendable, Equatable) has exactly these 16 stored properties, encoded under these keys: `alwaysIgnorePirates`, `alwaysIgnorePolice`, `alwaysIgnoreTradeInOrbit`, `alwaysIgnoreTraders`, `autoFuel`, `autoRepair`, `continuousAttack`, `continuousAttackFleeing`, `disableOpponents`, `newsAutoPay`, `newsAutoShow`, `remindLoans`, `reserveMoney`, `showTrackedRange`, `trackAutoOff` (all `Bool`) and `leaveEmpty` (`Int`). They mirror C# `GameOptions` one to one, and no other per-save option exists; a test enumerates the encoded keys. (source: GameOptions.cs:34-49, :124-146)
- **OPT-002** {M6} [M][W] Defaults: `alwaysIgnorePirates` false, `alwaysIgnorePolice` false, `alwaysIgnoreTradeInOrbit` false, **`alwaysIgnoreTraders` true**, `autoFuel` false, `autoRepair` false, `continuousAttack` false, `continuousAttackFleeing` false, `disableOpponents` false, `newsAutoPay` false, `newsAutoShow` false, **`remindLoans` true**, `reserveMoney` false, **`showTrackedRange` true**, **`trackAutoOff` true**, `leaveEmpty` 0. `GameOptions()` yields exactly these values. (source: GameOptions.cs:34-49)
- **OPT-003** {M6} [P] Palm defaults (the initial values of the Palm globals, used on first launch) differ in two places: **`alwaysIgnorePolice` true** [AlwaysIgnorePolice] and **`alwaysIgnoreTraders` false** [AlwaysIgnoreTraders]. The others are as OPT-002: AutoFuel, AutoRepair, AlwaysIgnorePirates, AlwaysIgnoreTradeInOrbit, ReserveMoney, Continuous, AttackFleeing and NewsAutoPay false; ShowTrackedRange, TrackAutoOff and RemindLoans true; LeaveEmpty 0. `newsAutoShow` and `disableOpponents` don't exist in Palm and are false. (source: Palm: Src/Global.c:613, :640-641, :648-653, :661, :663, :666-667, :671-672)
- **OPT-004** {M6} [M][W][P] `GameOptions.defaults(for: RulesetID)` returns OPT-002 for Modern and Windows 2.01 and OPT-003 for Palm. `NewGameConfig.options: GameOptions?` defaults to nil. `GameState(config:)` stores `defaults(for: config.ruleset)` when it is nil, and `config.options` normalized per OPT-008…010 otherwise. (source: Game.cs:94, GameOptions.cs:55-59, :101-117; Palm: Src/Traveler.c:1326-1700)
- **OPT-005** {M6} [P] A new Palm game always starts with `remindLoans = true` and `showTrackedRange = true`, even when `config.options` says otherwise. Palm's `StartNewGame` resets only these two and keeps every other preference from the previous game, which Parsec Merchant represents with the defaults template (OPT-019). (source: Palm: Src/Traveler.c:1649, :1666)
- **OPT-006** {M6} [M][W] A new Modern or Windows game stores `config.options` as given (after normalization), with no forced values. This is C#'s `new GameOptions(true)`, which loads `DefaultSettings.bin` when present and the class defaults otherwise. (source: Game.cs:94, GameOptions.cs:55-59, :101-117)

## 2. Changing options

- **OPT-007** {M6} [M][W][P] `Command.setOptions(GameOptions)` is accepted only while `phase == .docked` with no pending decision. Any other phase is rejected with `.notAllowedInPhase`, and an ended game with `.gameOver` (SCORE-013). An accepted command stores `options.normalized(for: ruleset)`, emits `GameEvent.optionsChanged`, draws no random numbers, and changes no other field (`cheatsUsed`, `reloadCount` and `ironman` included). C# opens Options only from the main window's menu (encounters and travel are modal), and Palm only from the docked forms' menu. So Palm's clearing of AutoAttack/AutoFlee when Options opens has nothing to clear here. (source: Form_SpaceTrader.cs:3742-3749; Palm: Src/AppHandleEvent.c:40, :188-191, :612)
- **OPT-008** {M6} [M][W] Dependencies, applied by `normalized(for:)` when `ruleset.flags.optionDependencies` is true: `continuousAttackFleeing` is forced false when `continuousAttack` is false; `alwaysIgnoreTradeInOrbit` is forced false when `alwaysIgnoreTraders` is false; `newsAutoShow` is forced false when `newsAutoPay` is false. A parent that is on leaves its dependent as given. This moves the C# dialog's rule (a dependent checkbox is unchecked and disabled while its parent is off) into the engine. (source: Form_Options.cs:381-431, :448-474)
- **OPT-009** {M6} [P] Palm has no dependencies (`optionDependencies` false): its two Options forms are independent checkboxes, so for example `continuousAttackFleeing` or `alwaysIgnoreTradeInOrbit` may be on while its parent is off. `normalized(for:)` forces `newsAutoShow` and `disableOpponents` to false in Palm, because those options don't exist there (NEWS-013, flag `newsAutoShowAvailable`; RUL-015, CMB-041). (source: Palm: Src/AppHandleEvent.c:199-302)
- **OPT-010** {M6} [M][W][P] `normalized(for:)` clamps `leaveEmpty` to 0…99 in every ruleset (ECO-044). The C# spinner allows 0–99. The Palm field accepts up to 4 digits and is displayed as `min(99, LeaveEmpty)`. Clamping a larger Palm value to 99 changes no outcome, because no ship has more than 99 free bays, so both values block every market purchase. (source: Form_Options.cs:285-300; Palm: Src/AppHandleEvent.c:212-221, Src/Cargo.c:874, :887)
- **OPT-011** {M6} [M][W][P] Options take effect at the next point where the engine reads them and are never applied retroactively. For example, switching `autoFuel` on while docked buys no fuel until the next arrival, and switching `newsAutoPay` on doesn't buy the current paper. (source: Game.cs:465-495, :3027-3045)
- **OPT-012** {M6} [M][W][P] Decoding a save does not normalize options. A state whose options break OPT-008 (reachable only by editing a file) is accepted, and each field then acts on its own as specified in §3; the next `setOptions` normalizes it. (source: SAV-010)

## 3. What each option controls

Each option is read only at the points listed. A test flips each field in turn over a fixed scripted scenario per ruleset and checks that only the listed behaviours change.

- **OPT-013** {M6} [M][W][P] `autoFuel` (AutoFuel) and `autoRepair` (AutoRepair) control only the arrival auto-buy: all-or-nothing with cash in Modern and Windows (TRV-056, TRV-057, TRV-065, SHP-057), partial in Palm (TRV-064, SHP-058), with the warnings of ALR-007/008/010. Manual fuel and repair purchases ignore them. (source: Game.cs:465-503; Palm: Src/Traveler.c:2327-2350)
- **OPT-014** {M6} [M][W][P] `alwaysIgnorePirates` controls only whether a non-attacking pirate encounter is skipped (ENC-102). (source: Game.cs:857-860; Palm: Src/Traveler.c:2033-2038)
- **OPT-015** {M6} [M][W][P] `alwaysIgnorePolice` controls only whether a police encounter is skipped: Modern and Windows skip every type except `policeAttack` and `policeInspect`, including `policeSurrender` (ENC-105); Palm skips only `POLICEIGNORE` and `POLICEFLEE` (ENC-106). (source: Game.cs:906-911; Palm: Src/Traveler.c:1985-1990)
- **OPT-016** {M6} [M][W][P] `alwaysIgnoreTraders` ("Traders") skips trader ignore and flee encounters, and `alwaysIgnoreTradeInOrbit` ("Ignore dealing traders") skips trader buy and sell offers (ENC-108 Modern and Windows, ENC-109 Palm). Neither affects trades the player starts. (source: Game.cs:997-1004; Palm: Src/Traveler.c:2084-2096)
- **OPT-017** {M6} [M][W][P] `leaveEmpty` reduces the free bays only for purchases at the system market (ECO-046). Trade-in-orbit purchases (ECO-068), plunder, scooping and special cargo ignore it. (source: Game.cs:560-575; Palm: Src/Cargo.c:874, :887)
- **OPT-018** {M6} [M][W][P] `reserveMoney` changes only the cash-to-spend figure: Modern and Windows reserve insurance, interest, mercenaries and the wormhole tax (ECO-042, BNK-054); Palm reserves mercenaries and insurance (ECO-043, BNK-055). It applies to the purchases listed in BNK-056 and, in Palm, the newspaper (NEWS-005). (source: Commander.cs:253-259; Palm: Src/Traveler.c:1234-1239)
- **OPT-019** {M6} [M][W][P] `newsAutoPay` makes reading an unpaid, affordable paper charge it without asking (NEWS-006). `newsAutoShow` is acted on by the app, which requests the paper after an arrival and when a new game starts (NEWS-012); it exists only in Modern and Windows (NEWS-013). (source: Game.cs:328-329, :3027-3045, Form_SpaceTrader.cs:3702-3703; Palm: Src/SystemInfoEvent.c:406)
- **OPT-020** {M6} [M][W][P] `remindLoans` gates only the 5-day debt reminder (BNK-034, BNK-036, BNK-037, TRV-054). The large-debt warning is not affected. (source: Game.cs:332-340; Palm: Src/Traveler.c:2226)
- **OPT-021** {M6} [M][W][P] `trackAutoOff` clears `trackedSystem` when the player arrives at the tracked system (TRV-050 step 1; Palm arrival). This includes arrivals by wormhole and by the direct-warp cheat (CHEAT-022), because all of them run the arrival pipeline. (source: Game.cs:315-316; Palm: Src/Traveler.c:2261-2263)
- **OPT-022** {M6} [M][W][P] `showTrackedRange` is display-only: no engine code reads it, so flipping it changes no `StepResult` for any command sequence. Its effect, showing "N parsecs to <system>" for the tracked system, is specified by MAP for M8 (UI). (source: Form_SpaceTrader.cs:3957-3960; Palm: Src/WarpFormEvent.c:196)
- **OPT-023** {M6} [M][W][P] `continuousAttack` and `continuousAttackFleeing` control only encounter auto-repeat (CMB-062…069, ENC-187, ENC-189). `resolve` behaves as if both were on (ENC-190). Palm stores `AttackFleeing` but never reads it (CMB-063). (source: Game.cs:1273-1281; Palm: Src/Encounter.c:1445, :1569, :1617)
- **OPT-024** {M6} [M][W] `disableOpponents` gates only the no-damage disable attempt (CMB-021, CMB-040); it does not exist in Palm (CMB-041, OPT-009). (source: Game.cs:1320-1325)

## 4. Options sheet and defaults template (app)

- **OPT-025** {M7} [UI] [M][W][P] **Game › Options…** (⌥⌘O) opens a sheet that is disabled when no game is loaded, when the game has ended, and while the phase is not `.docked`. Groups follow the C# dialog: arrival (full tanks, full hull repairs); newspaper (always pay, show on arrival); tracking (show range to the tracked system, stop tracking on arrival); money (remind about loans, reserve money for warp costs, a 0–99 stepper for "cargo bays to leave empty"); "always ignore when it is safe" (Pirates, Police, Traders, and Ignore dealing traders); combat (continuous attack and flight, continue attacking a fleeing ship, attempt to disable opponents). OK sends `setOptions`, Cancel discards. Every control has an `accessibilityIdentifier` and every label comes from `Localizable.xcstrings`. (source: Form_Options.cs:137-374; UX-VISION §2, §12)
- **OPT-026** {M7} [UI] [M][W] In Modern and Windows, a dependent control is disabled and shown off while its parent is off (OPT-008). In Palm, no control is disabled for dependencies, and "show newspaper on arrival" and "attempt to disable opponents" are hidden (OPT-009). (source: Form_Options.cs:409-431; Palm: Src/AppHandleEvent.c:199-302)
- **OPT-027** {M7} [UI] [M][W][P] The sheet's **Save as Defaults** writes the current sheet values as JSON-encoded `GameOptions` to `UserDefaults` under `defaultGameOptions.<rulesetID>`. **Load from Defaults** fills the sheet from that key, or from `GameOptions.defaults(for:)` when the key is absent (C# instead showed a file error). New Game and Quick Start pass the stored template of the chosen ruleset as `NewGameConfig.options`, or nil if there is none. This replaces C#'s `DefaultSettings.bin` and Palm's carry-over of preferences between games. (source: Form_Options.cs:437-446, GameOptions.cs:101-122; Palm: Src/Traveler.c:1326-1700)

## 5. App-wide settings and dropped classic options

- **OPT-028** {M7} [UI] [M][W][P] App-wide settings live in `UserDefaults` and are edited in Settings (⌘,): General (Text Size, Fast travel default off, arrival report style, tactical readout default on), Sound (master, effects and music volumes, ambient music default off, mute when inactive), Intelligence (Foundation Models flavor) and Advanced (reset tips, achievements and high scores). None of them is stored in a save, read by the engine, or able to change game state or RNG draws. Their details are owned by UI-SHELL, AUD, LLM and INT. (source: UX-VISION §2, §5.1, §5.2, §8; PRD §6.6)
- **OPT-029** {M6} [P] Palm preferences that are not game options are not part of `GameOptions` (OPT-001), and each is mapped or dropped. AlwaysInfo (chart goes to system info) and RectangularButtonsOn are dropped as Palm navigation and OS-skin settings. TextualEncounters is dropped because the encounter view always has text and VoiceOver labels. UseHWButtons becomes the encounter keyboard shortcuts (UX-VISION §10). Shortcut1–4 become the standard toolbar. SharePreferences and IdentifyStartup are dropped with Switch Game, which slots replace (SAV-051). PriceDifferences becomes a view toggle of the trade-intelligence price list (INT), not a saved option. (source: Palm: Src/Global.c:654-677, Src/AppHandleEvent.c:199-302, Src/Merchant.c:329-393)

## 6. API names proposed by this spec

- `GameOptions.defaults(for: RulesetID)` (OPT-004) and `GameOptions.normalized(for: Ruleset)` (OPT-008…010).
- `NewGameConfig.options: GameOptions?` (OPT-004).
- Ruleset flag `optionDependencies` (true in Modern and Windows 2.01, false in Palm; OPT-008/009).
- `UserDefaults` key `defaultGameOptions.<rulesetID>` (OPT-027).
- `GameEvent.optionsChanged` already exists; no new event.

## 7. Notes

- **Existing struct**: the `GameOptions` in GameState.swift already has all 16 C# options with the C# defaults. No classic option is missing. What is missing is the Palm defaults (OPT-003/004), `normalized(for:)`, the `NewGameConfig.options` input and the docked-only check: `apply(.setOptions)` currently stores the value unchanged in every non-ended phase.
- **Research discrepancy**: research 01 §12 and 02 §6 give only the C# defaults. Palm's first-launch defaults invert the police and trader always-ignore defaults (Src/Global.c:648-649), which the research doesn't mention. Research 04 §5 lists the Palm options without defaults.
- C# lets the Options dialog open with no game, with OK disabled so only defaults can be saved or loaded (Form_Options.cs:79-84, ALR-124). Parsec Merchant disables Game › Options without a game instead (UX-VISION §2). Editing the defaults template without a game is therefore not offered; this is a possible later Settings addition.
