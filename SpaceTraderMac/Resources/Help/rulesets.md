# Rulesets

Every game uses one ruleset, chosen when it starts:

- **Modern** (recommended): the Windows 2.01 game with known bugs fixed and some Palm behaviour restored.
- **Windows 2.01**: faithful to the C# port, quirks included.
- **Original Palm 1.2.2**: the original game, with 120 systems and without some later quests, shipyards and disruptors.

The ruleset is part of the galaxy code, so a friend who enters your code plays the same galaxy.
